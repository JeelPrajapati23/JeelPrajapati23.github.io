PR Review Agent

Two AI reviewers read every pull request and post fixes you can apply with one click.

  • A security agent and a performance & logic agent review the diff separately, then a third merges their findings.
  • Fail-closed: if the review cites a file the agents never opened, it isn't posted.
  • Runs the PR's own tests in a sandbox with every secret stripped out, and resumes cleanly after a crash.

Retrieval-augmented generation · Legal

ClauseIQ

Ask questions about your contracts, or compare several at once, and every answer is fact-checked against the source.

  • Hybrid search combines vectors and keywords, reranks with Cohere, then expands each hit to its full clause.
  • Each answer is split into claims, and each claim must be backed by a quote to pass.
  • Accounts with isolated workspaces, an audit log and admin panel, deployed with CI/CD.

reachfix

Finds which of your projects a vulnerability reaches, through which dependencies, and the smallest upgrade that fixes it.

  • A dependency graph built from npm lockfiles and OSV data, plus semantic search over advisory text.
  • Suggested fixes respect the version ranges every other package already declares.
  • Scan your own package-lock.json in the browser, or use it from Claude Code as an MCP server.

How I
build

The same three habits run through every project above.

Test it like it's production

Each evaluation runs the real pipeline, and a different model does the grading, so nothing grades its own work.

Refuse when unsure

No relevant context means a refusal with zero LLM calls. An ungrounded review becomes a failure status, not a guess.

Build for the free tier

Token budgets, rate limits and cold starts shaped these systems as much as the features did.
